## Description

Begin learning how to program a microcontroller using the Arduino IDE.

The primary objective is to learn how to interact with hardware through programming and use this as a foundation and stepping stone for larger, more ambitious projects. 

With each objective, I will save the individual code, a wiring diagram, and a brief what I learned/notes. 

I may change the objectives as I go through them, but everything will be recorded in the git history. 

## Objectives

### LED Basics

- [x] 0.1 - Blink an LED once every second indefinitely. 
- [ ] 0.2 - Blink two LEDs together once every second indefinitely. 
- [ ] 0.3 - Using two LEDs, alternate which one is on and off once every second indefinitely. 
- [ ] 0.4 - Gradually increase and decrease the brightness of an LED indefinitely. 
- [ ] 0.5 - Blink an LED in the sequence of SOS in morse code. 
- [ ] 0.6 - Blink two LEDs at different rates.
